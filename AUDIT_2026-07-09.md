# DsatGuru — Full Platform Audit & Fix Plan (2026-07-09)

Multi-agent audit across **student / admin / tutor** roles. 14 finder lenses → 103 findings → 96 verified (7 refuted) → ranked below. Backup before this work: git tag `pre-audit-fixes-20260709` / branch `backup/pre-audit-fixes-20260709`.

## Executive summary
The biggest problem is **test visibility & assignment authorization**: the student "Available Tests" page is wired to a staff-only, assignment-blind endpoint, so students either see "Couldn't load tests" or see **every** test in the system (the "#1 complaint: tests I was never assigned show up"), and any student can pull any test by ID to read the answer key and submit a graded session. A second Critical class is **data loss & wrong scores**: timed tests silently discard all answers on focus loss while claiming they saved, module completion always shows "Score 0", single-section tests fabricate a phantom "Math 200", and completed sessions can be re-entered and overwritten. Nearly every downstream student surface (Test History review, Retest, Redo Queue, sat-test/demo/retest players, domain analytics) is half-built or renders raw LaTeX and can't handle grid-in questions. On staff side: account deactivation is a no-op, tutors can read/overwrite data they don't own, and tutor pages are broken by a pervasive `assignedTutor`-vs-`assignedTutors` field bug plus case-sensitive email lockouts.

## CRITICAL
- **C1** — `app/dashboard/tests/page.js`: Available Tests page is assignment-blind (fetches staff-only `/api/admin/tests`) → leaks unassigned tests or 403-breaks. **THE #1 complaint.**
- **C2** — `app/api/admin/tests/[id]/route.js` + `POST /api/test-sessions`: any student can pull any test by ID (answer key leaked) and take/grade unassigned tests; `showExplanation` is mass-assignable.
- **C3** — `app/dashboard/tests/[id]/start/page.js`: timed test auto-submits on any focus loss and **silently discards all answers** while telling the student it saved; self-practice is needlessly proctored.
