Q1
The measure of angle R is 2π/3 radians. The measure of angle T is 23π/18 radians greater than the measure of angle R. What is the measure of angle T, in degrees?
Options
A. 120
B. 230
C. 350
D. 700
Correct Answer:
C
Topic
Radian measure and degree conversion
Difficulty:
Medium
Short Explanation
Shortcut: add the radian measures first, then convert once. Since 2π/3 = 12π/18, T = 12π/18 + 23π/18 = 35π/18. Then (35π/18) · (180/π) = 350°. Pattern: same-denominator radian addition followed by a clean degree conversion.
Long Explanation
Step 1: Convert 2π/3 to eighteenths: 2π/3 = 12π/18.
Step 2: Add the increase: 12π/18 + 23π/18 = 35π/18.
Step 3: Convert radians to degrees using π radians = 180°.
Step 4: (35π/18) · (180/π) = 35 · 10 = 350.
Shortcut placement: The shortcut fits at the beginning — combine the fractions first, so you only convert one angle.

Q2
In the xy-plane, the point (p, r) lies on the line with equation 4x + 3y = c, where c, p, and r are nonzero constants. The point (7p, 11r) lies on the line with equation x + y = c. Which expression must be equivalent to p/r?
Options
A. −8/3
B. −3/8
C. 3/8
D. 8/3
Correct Answer:
A
Topic
Linear equations and systems
Difficulty:
Medium-Hard
Short Explanation
Shortcut: plug in both points, then use the repeated constant c. From the first line, 4p + 3r = c. From the second line, 7p + 11r = c. Set them equal: 4p + 3r = 7p + 11r, so −3p = 8r and p/r = −8/3. Pattern: when two expressions equal the same constant, set them equal immediately.
Long Explanation
Step 1: Substitute (p, r) into 4x + 3y = c: 4p + 3r = c.
Step 2: Substitute (7p, 11r) into x + y = c: 7p + 11r = c.
Step 3: Set the two expressions equal because both equal c: 4p + 3r = 7p + 11r.
Step 4: Move terms: −3p = 8r.
Step 5: Divide by r and by −3: p/r = −8/3.
Shortcut placement: The shortcut is recognizing that you never need to solve for c.

Q10
The expression 6x⁴ + 17x² + 5 can be rewritten as (3x² + a)(2x² + b), where a and b are positive integers, or as (3x² + c)(2x² + d), where c and d are positive non-integers. What is the value of a + c?
Options
A. 8.5
B. 17.5
C. 7.5
D. 1
Correct Answer:
A
Topic
Polynomial factoring and coefficient comparison
Difficulty:
Hard
Short Explanation
Shortcut: (3x² + a)(2x² + b) = 6x⁴ + (3b + 2a)x² + ab. For integers: ab = 5 and 3b + 2a = 17, giving a = 1, b = 5. For non-integers: cd = 5 and 3d + 2c = 17, giving c = 7.5. Thus a + c = 8.5. Pattern: compare coefficients, not roots.
Long Explanation
Step 1: Expand (3x² + a)(2x² + b): middle coefficient is 3b + 2a, constant is ab.
Step 2: We need ab = 5 and 3b + 2a = 17.
Step 3: Integer factors of 5: a = 1, b = 5 works since 3(5) + 2(1) = 17.
Step 4: For (3x² + c)(2x² + d): cd = 5 and 3d + 2c = 17.
Step 5: Substitute c = 5/d: 3d + 10/d = 17 → 3d² − 17d + 10 = 0 → d = 5 or d = 2/3.
Step 6: Non-integer case: d = 2/3, c = 5/(2/3) = 7.5. So a + c = 1 + 7.5 = 8.5.
Shortcut placement: The shortcut is testing factor pairs for the integer case before doing algebra.
